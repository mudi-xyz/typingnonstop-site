10-key typing test: how it is scored and how to practise

A 10-key test checks how quickly and accurately you can enter numbers on the numeric keypad, the block of keys on the right of a full-size keyboard. It appears in applications for data entry, accounting, payroll, billing and similar office jobs. It is scored differently from a normal typing test, so a good words-per-minute score does not automatically mean a good 10-key score.

What the test measures

You are shown rows of numbers, sometimes with a decimal point or simple operators, and you copy them using the keypad. Most tests expect you to press Enter after each entry, and that Enter counts as a keystroke. The result is usually given as keystrokes per hour (KPH) together with an error count or an accuracy percentage. The number row above the letters is not the keypad, and tests are built for the keypad.

How the score is worked out

KPH is the number of keystrokes divided by the seconds you took, multiplied by 3,600. A short test is projected to a full hour, so a two-minute run can still produce an hourly figure. Many employers set a minimum accuracy next to the speed, because a single wrong digit changes a value completely.

What speeds employers ask for

Job-test preparation sources commonly describe around 8,000 KPH as an average keypad speed and 10,000 KPH or more as a strong, job-ready result. One assessment-preparation provider states that typical minimums are 8,000 KPH for an alphanumeric data entry test and 10,000 KPH for a 10-key test, in both cases with accuracy above 95 percent. These are general figures, not rules. The number in your own job advert is the one that counts.

How to practise

  • Keep your eyes on the numbers you are copying, not on the keypad. Looking down breaks your rhythm and loses seconds on every row.
  • Start slowly with groups of four to six digits and press Enter after each group, exactly as the test will.
  • Work for accuracy first. Speed comes after you can complete several rows without a single wrong digit.
  • Practise in short sessions of five minutes, and finish each one by checking which digits you mistyped.
  • Use a keyboard that has a keypad. Many laptops do not, so a cheap external keypad or keyboard is worth having if the job needs this skill.

Common mistakes

  • Reading a number wrongly, especially when two digits look alike in a small font.
  • Hesitating at the decimal point and losing rhythm.
  • Forgetting Enter after a row, which can shift every later entry.
  • Using the number row because it feels familiar, then discovering the test needs the keypad.

Frequently asked questions

What is a good 10-key speed?

Around 8,000 keystrokes per hour is commonly described as average, and 10,000 or more is usually seen as strong. Always check the minimum in the job advert, and aim to beat it with high accuracy.

Is a 10-key test the same as the number row?

No. A 10-key test uses the numeric keypad on the right side of a full-size keyboard. The number row above the letters is a different layout and a different skill.

How is keystrokes per hour calculated?

Divide the number of keystrokes by the seconds taken and multiply by 3,600. Many tests count the Enter key as a keystroke and also report your errors or accuracy.
